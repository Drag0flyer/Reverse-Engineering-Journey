## 2. Static Analysis & Resolution
The initial exploration of the binary was performed using Ghidra's decompiler to reconstruct the logical algorithm without executing the file.

### Validation Mechanics:
1. **Argument Control:** The program intercepts user input directly through the standard `main` function by evaluating the argument count (`argc`).
2. **Input Handling:** Flow analysis shows that the program expects exactly one command-line argument (`argv[1]`). If no parameter is provided, the program terminates preventively.
3. **Secret Extraction:** By reviewing the pseudo-C code generated by the decompiler, the raw string expected by the comparison routine was clearly visible. This high-level static analysis was sufficient to extract the validation key directly.

> **Identified Solution:** `cccc@ccccc` where `c` represents any valid ASCII character.

---

## 3. Advanced Analysis: Internal Structure (Bonus)
Beyond the simple resolution via decompilation, I pushed the analysis down to the architectural level to study the physical structure of the system instructions:

* **Memory Addressing:** Deep dive into how local variables are handled on the stack relative to the base register (`RBP - 16`).
* **Opcode Decoding:** Manual breakdown of the **REX prefixe**, **Instruction opcode**, **ModR/M** byte, **SIB (Scale-Index-Base)**, **Displacement** and the **Immediate** suffix to mathematically understand how the x86_64 processor calculates indexing and physical addresses during array element accesses in RAM.

This purely theoretical phase validated the translation from hexadecimal opcodes to ASM instructions manually before moving on to automated dynamic tools later.

## 5. Exploitation & Patching
To bypass the validation logic completely, the binary was patched using a hex editor (HxD):
* **File Offset / Address:** `0x001011d7`
* **Original Bytes:** `75 7E` (`JNZ LAB_00101257`)
* **Patched Bytes:** `EB 2F` (`JMP short` targeting `LEA` at `0x00101208`)

This successfully forces the execution flow into the success block, printing `Nice Job!!` and the flag without checking the input parameters.
